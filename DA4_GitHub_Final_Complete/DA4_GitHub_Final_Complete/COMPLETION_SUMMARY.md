## Methodology Summary

### Dataset A: Customer Segmentation
1. **Baseline:** DummyClassifier (most_frequent)
2. **Models Tested:**
   - Gaussian Naive Bayes
   - Bernoulli Naive Bayes
   - Categorical Naive Bayes
   - TabTransformer (Transformer encoder for categorical embeddings + MLP)
3. **Model Selection:** Best Naive Bayes by mean 5-fold CV macro F1
4. **Test Evaluation:** Locked 20% held-out test set
5. **Analysis:** Confusion matrices, error analysis, prediction confidence

### Dataset B: Bank Marketing
1. **Target:** Term deposit subscription (yes/no)
2. **Features Excluded:** `duration` (leakage risk — only known after call)
3. **Models Tested:** Same Naive Bayes variants
4. **Model Selection:** Best Naive Bayes by mean 5-fold CV macro F1
5. **Evaluation:** Locked test set, metrics, error analysis
